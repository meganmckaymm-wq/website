# Sideform

Portfolio site for Megan Mckay's freelance studio, Sideform. Built with React, Vite, Tailwind and Lucide.

## Run it

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Edit your content in `src/data/content.js`. Images live in `public/images`, videos in `public/videos`.
